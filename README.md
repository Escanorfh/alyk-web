# إليك — صفحة التنزيل (build منشور)

المحتوى هنا ناتج بناء (build artifact) لصفحة الهبوط والتنزيل، لا كود مصدري.
الكود المصدري للتطبيق ولصفحة الهبوط في مستودع المشروع الخاص.

## التحميل

- أندرويد (arm64-v8a): `downloads/aalyk-android-arm64-v8a-v1.1.0.apk`
- بصمة التحقق لكل ملف: ملف `.sha256` مجاور، والقائمة الكاملة في `downloads.json`

الصفحة تقرأ `downloads.json` وقت التشغيل، فلا يوجد رابط تحميل يشير لملف غير موجود.

## إعادة النشر

من مستودع المشروع:

```
cd site && npm run build
# انسخ محتويات dist إلى هذا المستودع ثم ادفع إلى main
```

البناء يستخدم `base: './'` في Vite، لذا يعمل من جذر النطاق أو من مسار فرعي مثل `/alyk-web/` دون تعديل.
